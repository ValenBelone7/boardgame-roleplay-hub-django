# Arcana — API

Backend de **Arcana**, tienda de juegos de mesa y de rol que además organiza torneos, partidas de rol y noches de juegos en su local, y guarda la tabla de ganadores y las leyendas de cada evento.

API REST construida con Django y Django REST Framework, gestionada con uv.
